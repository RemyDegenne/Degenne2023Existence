## Lemma 11: the base measure of the family must be nonzero

- **Statement:** `Degenne2023Existence.isLDP_empiricalMean_expFamily`, as frozen at the end of
  phase 1.
- **Problem:** the statement assumes only that `μ` is a mean of the exponential family generated
  by `ρ` with the statistic `id`. For the zero measure `ρ = 0`, `integrableExpSet id 0 = univ` and
  `cgf id 0 = 0`, so the family has the single mean `0` (LMLExplore's
  `Measure.expFamilyMeans_zero_measure`), and its member of mean `0` is the zero measure. For
  `n ≥ 1` the laws `P n` of the empirical means are then the zero measure and
  `(1 / n) log P n univ = ⊥`, while the rate function `x ↦ dbar(x, 0) = rateFunction id 0 x` is `0`
  at `0`: the lower bound of the large deviation principle fails for `univ`,
  `-(inf_x dbar(x, 0)) = 0 > ⊥ = liminf_n (1 / n) log P n univ`. The paper is not affected: its
  arms are distributions of a one-parameter exponential family, a family of probability measures
  generated by a nonzero measure, which the Lean statement leaves implicit.
- **Evidence:** the following check compiles against the project (`lake env lean`, round of
  2026-11-09):

  ```lean
  import Degenne2023Existence.D2023.Lemma11

  open MeasureTheory LMLExplore Filter

  example : ¬ (IsLDP (fun n ↦ (Measure.pi fun _ : Fin n ↦
          (0 : Measure ℝ).expFamily id ((0 : Measure ℝ).natParam id 0)).map
          fun x : Fin n → ℝ ↦ (∑ i, x i) / (n : ℝ))
        (fun x ↦ (0 : Measure ℝ).expFamilyRate id x 0) ∧
      IsGoodRateFunction (fun x ↦ (0 : Measure ℝ).expFamilyRate id x 0)) := by
    rintro ⟨h, -⟩
    have h1 := h.neg_iInf_interior_le_liminf Set.univ
    have hinf : (⨅ x ∈ interior (Set.univ : Set ℝ),
        (0 : Measure ℝ).expFamilyRate id x 0) = 0 := by
      refine le_antisymm ((iInf₂_le 0 (by simp)).trans ?_) zero_le
      simp
    have hev : ∀ᶠ n : ℕ in atTop, ENNReal.log (((Measure.pi fun _ : Fin n ↦
          (0 : Measure ℝ).expFamily id ((0 : Measure ℝ).natParam id 0)).map
          fun x : Fin n → ℝ ↦ (∑ i, x i) / (n : ℝ)) Set.univ) / (n : EReal) = ⊥ := by
      filter_upwards [eventually_ge_atTop 1] with n hn
      have : Measure.pi (fun _ : Fin n ↦
          (0 : Measure ℝ).expFamily id ((0 : Measure ℝ).natParam id 0)) Set.univ = 0 := by
        rw [Measure.pi_univ]
        simp only [Measure.expFamily_zero_measure, FunLike.coe_zero, Pi.zero_apply]
        exact Finset.prod_eq_zero (i := ⟨0, hn⟩) (Finset.mem_univ _) rfl
      rw [Measure.map_apply (by fun_prop) MeasurableSet.univ, Set.preimage_univ, this,
        ENNReal.log_zero]
      exact EReal.bot_div_of_pos_ne_top (by exact_mod_cast hn) (EReal.natCast_ne_top n)
    rw [hinf, liminf_congr hev, liminf_const] at h1
    simp at h1
  ```

  With the hypothesis `[NeZero ρ]`, the statement is `LMLExplore.isLDP_cramer_expFamily`
  (`Degenne2023Existence/ForLMLExplore/Probability/LargeDeviations/Cramer.lean`), proved from
  Cramér's theorem `LMLExplore.isLDP_cramer`; the corrected Lemma 11 is then
  `isLDP_cramer_expFamily hμ`. Recommended decision: add the hypothesis `[NeZero ρ]` (or
  `ρ ≠ 0`).
